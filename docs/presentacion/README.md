# Presentación para la defensa

`index.html` es una presentación autocontenida de 15 diapositivas (1280×720) con la paleta de SGM-TB.

- **Presentar:** abrir `index.html` en el navegador y pulsar F11. Flechas ← → (o clic) para avanzar y retroceder;
  `Inicio`/`Fin` para ir a la primera/última; `#7` en la URL abre la diapositiva 7.
- **PDF:** `SGM-TB_defensa.pdf` (una página por diapositiva). Para regenerarlo: tecla `P` → *Guardar como PDF*,
  márgenes *Ninguno*, o con Chromium: `chromium --headless --print-to-pdf=SGM-TB_defensa.pdf --no-pdf-header-footer index.html`.
- **Capturas** (`img/`): tomadas con el navegador de pruebas sobre la BD desechable `sgmtb_test` con recorridos
  SIMULADOS (así se indica en la diapositiva 7). Para la defensa conviene reemplazarlas por capturas con los
  recorridos reales del trabajo de campo.
- Cifras al 20/11/2026: `docs/PLAN_PRUEBAS.md`, `docs/CALIDAD_SOFTWARE.md`, `docs/MEJORA_CONTINUA.md`.
