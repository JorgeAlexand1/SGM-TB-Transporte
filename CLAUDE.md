# Reglas del Proyecto
- Antes de realizar cambios grandes o tras modificar cada archivo, actualiza brevemente `.claude_progreso.md` con: (1) qué se completó, (2) qué archivo se está editando ahora, y (3) los pasos exactos pendientes.
- Si una sesión se interrumpe, lee `.claude_progreso.md` y ejecuta `git diff` al iniciar para retomar el trabajo sin repetir pasos.
